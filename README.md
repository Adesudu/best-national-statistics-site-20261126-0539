NusaData — Indonesia in Numbers. A national statistics site for Indonesia: population, economy, all 38 provinces, and society — every figure with its source and year (BPS, World Bank, Dukcapil). Six pages on hash routes, hand-drawn SVG charts, a searchable and sortable province table, and a phone layout. Static files only, no network requests, no framework.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the overview page. Use the top nav to reach Population, Economy, Regions, Society and Sources.
